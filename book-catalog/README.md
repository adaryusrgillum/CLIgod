# Digital Book Catalog with Page Flip Viewer

Interactive digital catalog for "The Small Business AI Revolution Series" - 40 books with realistic page flip animations.

## Features

✨ **Interactive Book Catalog**
- Grid layout showcasing all 40 books
- Color-coded book covers
- Category badges and metadata

🔍 **Search & Filter**
- Real-time search across titles and descriptions
- Filter by category (Foundation, Strategy, Operations, etc.)
- Instant results

📖 **Page Flip Reader**
- Realistic page turn animations
- Keyboard navigation (Arrow keys, Escape)
- Fullscreen mode
- Page indicator
- Smooth transitions

🎨 **Beautiful Design**
- Gradient book covers
- Responsive layout
- Modern UI with smooth animations
- Mobile-friendly

## How to Use

### Running Locally

1. **Open the catalog:**
   ```bash
   # Simply open index.html in your web browser
   # Or use a local server:
   cd book-catalog
   python3 -m http.server 8000
   # Then visit: http://localhost:8000
   ```

2. **Browse books:**
   - Scroll through the grid of 40 books
   - Use search box to find specific titles
   - Filter by category using the dropdown

3. **Read a book:**
   - Click "Read Preview" on any book
   - Use arrow buttons or keyboard arrows to turn pages
   - Press Escape or click "Close" to exit
   - Click fullscreen button for immersive reading

### Keyboard Shortcuts

- `←` / `→` - Previous/Next page
- `Esc` - Close reader
- Mouse wheel - Scroll through pages

## Customization

### Adding Real Book Content

Edit `book-data.js` to add actual book content:

```javascript
const bookContent = {
    1: {
        title: "Book Title",
        chapters: [
            {
                title: "Chapter 1",
                content: "Full chapter content..."
            }
        ]
    }
};
```

### Changing Colors

Edit the color scheme in `styles.css`:

```css
:root {
    --primary-color: #2563eb;
    --secondary-color: #7c3aed;
    /* Add more colors */
}
```

### Adding More Books

Add to the `booksData` array in `book-data.js`:

```javascript
{
    id: 41,
    title: "New Book",
    category: "category-slug",
    description: "Book description",
    pages: 150,
    color: "#667eea"
}
```
